Script2Video 取扱説明書

台本と収録音声から、音声・字幕・タイムラインを作り、画像・動画の素材と縦書きの吹き出し・ト書きを合成して、完成動画 output.mp4 を書き出すコマンドラインツールです。この説明書は 2026-10-16 時点の main の状態(計画 2a〜2d の取り込み後)に合わせています。

1. 概要と作業の流れ

すべてのコマンドは script2video <コマンド> <台本.txt> の形で使い、台本のあるフォルダ(以下「台本フォルダ」)を基準に読み書きします。1 本の動画は、次の順に作ります。

1
台本を書く
台詞・シーン・カット・ト書き
→
2
number
台詞・シーン・カット・ト書きに番号を付ける
→
3
収録する
台詞ごとの wav を voices/ に
→
4
build
音声・字幕・タイムラインを作る
→
5
prompts
素材を作るためのプロンプト
→
6
素材を置く
画像・動画を tracks/ に
→
7
bubbles
吹き出し・ト書きを画面で調整(任意)
→
8
render
output.mp4 を書き出す
script2video number  第1話.txt
script2video build   第1話.txt [--voice-dir 収録/] [--config 設定.toml] [--no-cache]
script2video prompts 第1話.txt [--config 設定.toml]
script2video bubbles 第1話.txt [--config 設定.toml] [--port N] [--no-open]
script2video render  第1話.txt [--config 設定.toml]
台本や収録を直したら

build をやり直してから、prompts・bubbles・render に進みます。timeline.json には台本と音声の SHA-256 が記録されていて、後のコマンドが食い違いを検査します。

2. インストールと前提

インストール(配布パッケージ)

Rust は不要です。宇摩コードワークスのサイトから Script2Video_v0.1.0.zip をダウンロードし、PATH の通ったフォルダに展開します。ffmpeg は同梱していないので、展開した install-ffmpeg.ps1 を PowerShell で実行して入れます。script2video --help で動作を確認します。

インストール(ソースからビルド)

# リポジトリの直下で実行。~/.cargo/bin/script2video.exe に入ります(PATH に ~/.cargo/bin が必要)
cargo install --path crates/s2v-cli --locked
script2video --help

コードを更新したら、同じコマンドをもう一度実行して入れ直します(同じ版でも入れ直すなら --force)。

前提

もの必要なコマンド内容
ffmpeg・ffprobe 6.0 以上bubbles・renderPATH に置くか、[render] ffmpeg・ffprobe で場所を指定します。git の日付版(2023 年以降)も使えます。版が古いと失敗し、版を読み取れないときは警告して続けます。
縦書きのフォントbubbles・render既定は C:\Windows\Fonts\YuGothM.ttc(游ゴシック Medium)。縦書き用の機能(vrt2 か vert)と縦書きの寸法(vhea・vmtx)が必要です。
ブラウザbubbles既定のブラウザ(Chrome で確認済み)。Windows では自動で開きます。

3. 台本フォルダの構成

台本フォルダ/
├─ 第1話.txt              台本
├─ 第1話.bak .ids .html   number の出力(バックアップ・番号の記録・閲覧用の台本)
├─ voices/                収録(S01_L001.wav …)。build は読むだけ
├─ full_dialogue.wav      build: 台詞・BGM・SE を合成した音声
├─ timeline/
│   ├─ timeline.json      build: 後のコマンドが読む正本(v3)
│   ├─ subtitles.srt      build: 字幕
│   └─ timeline.fcpxml    build: 動画編集ソフト(Filmora)向け
├─ tracks/                build: dialogue.wav / bgm.wav / se.wav
│                         あなたが置く: 画像・動画の素材(S01.png、S01_C02.mp4 …)
├─ prompts/               prompts: S01.md … と index.md
├─ bubbles.json           bubbles: 手動で置いた吹き出し・ト書き(.bak も)
├─ output.mp4             render: 完成動画
├─ output.stale.mp4       build が改名した前回の output.mp4
├─ work/                  中間ファイル(消してよい)
└─ Process.log            処理の記録・警告・エラー
  • 台本のファイル名に、予約名(full_dialogue.wav・Process.log・output.mp4・output.stale.mp4・bubbles.json・bubbles.json.bak・.script2video.lock・prompts)は使えません(大文字小文字を区別しません)。
  • work/・tracks/・timeline/・voices/・prompts/ をリンク(シンボリックリンク・ジャンクション)や台本フォルダの外にしないでください。どのコマンドも何も消さずに止まります。
  • 同じ台本フォルダで 2 つのコマンドを同時に動かすと、後から始めた方が「別の script2video が実行中」で止まります(.script2video.lock による排他)。

4. 台本の書き方

詳しい規則は 台本仕様.md を参照してください。ここでは主な書き方をまとめます。

@scene 居間
朝の居間。明るく静かな雰囲気。
@pause
sentence 500
cast 300
paragraph 1000
@cast
田中:田中,pan=-25,distance=1.2
30代の男性。短髪で、紺のカーディガンを着ている。

佐藤:佐藤,pan=25,distance=1.2
20代の女性。肩までの黒髪。白いシャツ。

@script
#paragraph 朝の居間
#visual (image) 朝の光が差し込む居間。
#note 翌朝、居間。
田中:おはよう。今日は早いね。
佐藤:おはよう。コーヒー、淹れたよ。
#cut
#visual (video loop) カーテンが風に揺れる。
田中(volume=-0.2):ありがとう。いい香りだ。

セクション

セクション内容
@scene 名称場面。次の行に雰囲気の説明。音響の room_size=・reverb_wet=(0.0〜1.0)を書けます。
@pause無音の長さ(ミリ秒)。sentence 文の間、cast 話者の交替、paragraph シーンの間。
@assetbgm_dir = 絶対パス、se_dir = 絶対パス。
@cast役名:話者名,pan=度,distance=m,height=m,volume=倍率。定義行の次の行から空行までが、その役の外見(プロンプトに使います)。
@script台詞とコマンド。

台詞

[S01-L003] 役名(臨時パラメータ):台詞
  • [S01-L003] は台詞 ID で、number が書き込みます。自分で書くときは省略できます。
  • 役名と台詞の区切りは半角の : だけです(全角の : は区切りになりません)。
  • 臨時パラメータは @cast の値への増減です(pan・distance・height・volume)。
  • 台詞を重ねるときは overlap=ミリ秒(直前の台詞の終わりの何ミリ秒手前から)か、at=L003+500(指定の台詞の開始の何ミリ秒後から。別のシーンなら S01-L003)を書きます。

コマンド

コマンド意味
#paragraph[S02] 名称シーンの区切り。番号は number が書き込みます。名称は省略できます。
#cut[C02]シーンの中で素材を切り替えます(シーンの頭は暗黙の C01)。
#visual (印) 本文直前のカットの情景。印は image・video・loop(例 (video loop))。
#note[N01] 本文ト書き。動画では枠の中に縦書きで表示します。
#pause ミリ秒無音。台本の最後に書くと、その長さだけ音声の末尾の無音になります。
#bgm_start ファイル.wav / #bgm_stopBGM の開始と停止。
#se ファイル.wav at=L003+200 gain=-3効果音。at=・end=で台詞に合わせて置けます。
# コメント# の後に空白があればコメントです。

カット・情景・ト書き

  • カットは、その行の時点から、次の #cut かシーンの終わりまで続きます。カットごとに素材を 1 つ置きます(8. 素材の置き方)。
  • #visual の印: image・video は素材の種類の希望(省略すると未指定)、loop は動画の素材がカットより短いときに繰り返す指定です。loop が無い動画は、最後のコマで止まります。
  • ト書きは、その行の時点から、同じシーンの次の #note・次の #cut・シーンの終わりのうち、最も早いところまで表示します。
  • 吹き出しは、台詞の音声が鳴っている間だけ表示します。位置と大きさは自動で決まり、bubbles で手動に直せます。

5. number(番号付け)

script2video number 第1話.txt

台詞・シーン・カット・ト書きに番号を書き込みます([S01-L003]・#paragraph[S02]・#cut[C02]・#note[N01])。既存の番号は変えず、欠番も詰めません。台本名の .bak(書き換え前)・.ids(番号の記録)・.html(閲覧用)も出力します。

6. build(音声・字幕・タイムライン)

script2video build 第1話.txt
script2video build 第1話.txt --voice-dir 収録/     # 収録を別の場所に置いたとき

収録ファイル

  • 台詞ごとに 1 ファイル、モノラルの wav を voices/ に置きます。ファイル名は台詞 ID の - を _ にしたもの(S01_L003.wav)。番号の桁数は問いません(S01_L3.wav も同じ台詞)。
  • 台詞は自動で同じ音量(ラウドネス)にそろえます。

出力

ファイル内容
full_dialogue.wav台詞・BGM・SE の合成(24bit)
tracks/dialogue.wav bgm.wav se.wav動画編集ソフト用の別トラック(32bit 浮動小数)
timeline/timeline.json後のコマンドが読む正本(v3)
timeline/subtitles.srt字幕
timeline/timeline.fcpxmlFilmora 向け(3 トラック)
build は output.mp4 を作りません

前回の output.mp4 があれば、出力を始める時点で output.stale.mp4 に改名します(古い動画を新しいものと取り違えないため)。動画は render で作り直してください。

7. prompts(素材のプロンプトを作る)

script2video prompts 第1話.txt

timeline.json から、画像・動画を生成するためのプロンプトをカットごとに作り、prompts/ に書きます。

  • prompts/S01.md …: シーンごとのファイル。カットごとに、作る素材のファイル名・種類・長さ(動画と種類未指定のとき)・プロンプト本文(コピーしやすいようコードブロック)を書きます。
  • プロンプト本文の順: [prompts] style → シーン名 → #visual → 登場人物と外見 → [prompts] suffix。登場人物は、そのカットの間に話す人を台本の初出順に並べます。
  • prompts/index.md: 全カットの表(カット・ファイル名・種類・長さ・素材の有無)。tracks/ の誤り(重複・種類違い・リンク)は末尾の「tracks/ の確認事項」に書きます。
  • prompts/ の中で書き換え・削除するのは index.md と S<数字>.md だけです。自分のメモは別の名前(memo.md など)で置けます。

8. 素材の置き方

台本フォルダの tracks/ に、カットごとに 1 つ置きます。名前はカット ID から決まります。

カット ID素材のファイル名の例
S01-C01(シーンの頭)tracks/S01.png
S01-C02tracks/S01_C02.mp4
S03-C01tracks/S03.jpg
  • 拡張子: 画像は png・jpg・jpeg、動画は mp4・mov・webm(大文字小文字は区別しません。WebP は使えません)。
  • 同じカットに 2 つ置く(拡張子違いを含む)、画像のカットに動画を置くなど種類が台本と違う、HDR や BT.2020 の色の動画は、render がエラーにします。
  • 素材が足りないカットは、設定の [render] default_image があればその画像で代わりに書き出します(警告)。

9. bubbles(吹き出し・ト書きの配置を画面で調整する)

script2video bubbles 第1話.txt
script2video bubbles 第1話.txt --port 8765 --no-open

自動配置された吹き出し・ト書きを、ブラウザの画面で動かしたり、大きさ・尻尾・表示の時刻を直したりして、bubbles.json に保存します。render はこの配置を使います。調整しない項目は、毎回自動で配置されます。

  • 起動すると http://127.0.0.1:<ポート>/?token=… の 1 行を表示し、既定のブラウザで開きます(Windows)。開けなかったときや --no-open のときは、表示された URL を自分で開きます。
  • --port を省くと、空いているポートを自動で選びます。
  • 先に build を済ませておきます。ffmpeg・ffprobe とフォントの検査は render と同じです。

画面の構成

上状態(未保存の変更・保存の結果・警告)、「保存」「終了」のボタン
左: 一覧シーン → カット → 台詞・ト書き。「手動」「切詰」の印。クリックでその項目の開始のコマへ
中央: プレビュー動画と同じ縦横比。カットの素材を背景に、吹き出し・ト書きを render と同じ見た目で重ねる
右: 数値の欄x・y・幅・高さ・尻尾 dx/dy・開始のずれ(ms)・終了のずれ(ms)、「自動に戻す」
下: コマのスライダーと再生/停止再生中は full_dialogue.wav を鳴らし、動画の素材は消音で音声に合わせる
  • 時刻はコマ番号で扱います。表示の出入りやカットの切り替えのコマは、render と同じ計算です。
  • 動画の素材は、ループの指定があれば繰り返し、無ければ最後のコマで止まります(render と同じ)。
  • ブラウザで再生できない動画の素材は、サーバーが ffmpeg でコマの画像にして見せます。

操作

したいこと操作
項目を選ぶ左の一覧をクリック(その項目の開始のコマへ移ります)、またはプレビューの枠をクリック(重なっているときは前面のもの)
動かす本体をドラッグ。または矢印キーで 1px、Shift+矢印で 10px(数値の欄に入力中のときは、矢印キーは欄の操作になります)
大きさを変える四隅のつまみをドラッグ
尻尾の向きを変える尻尾の先のつまみをドラッグ
数値で指定する右の欄に入力し、Enter を押すか欄から離れると確定
表示の時刻をずらす「開始のずれ」「終了のずれ」(ミリ秒。±60000 まで)
自動の配置に戻す「自動に戻す」
保存する「保存」か Ctrl+S
文字が入らない大きさにはできません

小さすぎる大きさにすると、直前に確定した値に戻り、「確定できません: …文字が枠に収まりません」と理由が出ます。自動の項目は、手動の項目を避けて置き直されます。元に戻す・やり直しの機能はこの版にはありません。

保存と終了

  • 保存されるのは手動で置いた項目だけです。保存のたびに直前の bubbles.json を bubbles.json.bak に残します。
  • 「終了」は、未保存の変更があると確認を出します。タブを閉じるときも警告します。
  • ターミナルで Ctrl+C を押すとすぐに終わり、未保存の変更は失われます。
bubbles の起動中は、素材を差し替えられません

tracks/ の素材と full_dialogue.wav は、起動中ずっと上書き・削除・改名できないように開いています。差し替えるときは bubbles を終えてから行います。また、起動中は同じ台本フォルダで build や render を動かせません(ロック)。

「セッションが切れました」と出たら

bubbles を起動し直したときなどに出ます。そのページでは操作できないので、bubbles を起動し直して、新しく表示された URL を開いてください。URL の token は起動のたびに変わる使い捨ての合言葉です。

10. render(動画を書き出す)

script2video render 第1話.txt

build の出力・tracks/ の素材・bubbles.json(あれば)から、吹き出し・ト書き・音声を合成して output.mp4(H.264 + AAC、既定 1920×1080・30fps)を書き出します。中間ファイルは work/render/ に作ります(消してよい)。

  • 吹き出しとト書きは縦書きで描き、手動の配置が無い項目は自動で配置します。
  • 自動の吹き出しが長すぎて画面に入らないときは、画面の大きさに切り詰めて警告します(終了コード 1)。手動の項目の文字が保存した枠に入らないときは、枠を広げて警告します。
  • フォントに無い文字は、項目ごとに警告して代わりの字形で描きます。
  • 書き出した動画は、寸法・コマ数・音声の長さとずれを検査してから output.mp4 に置き換えます。失敗したときは前回の output.mp4 を変えません。
台本だけを直したとき

build の後に台本だけが変わっていると、警告(終了コード 1)を出して続けます。収録を変えた(full_dialogue.wav が timeline.json と食い違う)ときは失敗するので、build をやり直してください。

11. 設定(config.toml)

--config 設定.toml を省くと、同梱の config.toml を使います。全項目は同梱のファイルを参照してください。よく使うものは次のとおりです。

[render]

キー既定意味
width / height1920 / 1080解像度(偶数)
fps30フレームレート
fitcontain素材の収め方(contain は余白あり、cover は切り取り)
default_imageなし素材が無いカットの代わりの画像
font_pathC:\Windows\Fonts\YuGothM.ttc縦書きに使うフォント
ffmpeg / ffprobePATH からffmpeg・ffprobe の場所
jobs1カットを同時に作る ffmpeg の数

[prompts]

キー既定意味
style空プロンプトの先頭に付ける画風
suffix縦横比 16:9。画像の中に文字・吹き出しを入れない。プロンプトの末尾に付ける注意書き

12. 終了コードとログ

コード意味
0正常に終わりました
1警告があります(出力はできています)。Process.log を確かめてください
2失敗しました(出力していないか、前回の出力を残しています)

処理の記録・警告・エラーは、台本フォルダの Process.log に書きます。build は作り直し、prompts・bubbles・render は == render 2026-10-16 12:34:56 == のような区切り(時刻は UTC)を付けて追記します。

13. 困ったとき

症状・表示原因と対処
「別の script2video が実行中」同じ台本フォルダで他のコマンド(bubbles の起動中を含む)が動いています。終わるのを待つか、bubbles を終了してください。
「timeline.json がありません。先に build を実行してください」build をまだ実行していません。
「full_dialogue.wav が timeline.json と別の build のものです」収録や音声が変わっています。build をやり直してください。
「素材が足りません」tracks/ に素材を置くか、[render] default_image を指定します。prompts/index.md の「素材」の列で不足が分かります。
同じカットに素材が 2 つある・種類が違うどちらかを消すか、台本の #visual の印(image/video)を直します。
HDR・BT.2020 の動画でエラーBT.709(SDR)の動画に変換してから置きます。
「ffmpeg が見つかりません」「古すぎます」ffmpeg・ffprobe 6.0 以上を入れて PATH に置くか、[render] ffmpeg・ffprobe で場所を指定します。
フォントを読めない・縦書きの機能が無い[render] font_path に、縦書きに対応したフォント(vrt2 か vert、vhea・vmtx を持つもの)を指定します。
bubbles で「セッションが切れました」bubbles を起動し直し、新しい URL を開きます。
bubbles で素材が「素材なし」になる他のプログラムが素材を書き込みのために開いています。そのプログラムを閉じて、bubbles を起動し直します。

14. 現在の制限と未確認の事項

この版の制限

  • bubbles に元に戻す・やり直しの機能はありません。
  • bubbles のブラウザの自動起動は Windows だけです。
  • bubbles は同じ PC の他のプログラムからは守れません(他のウェブページ・他のローカルのサービスからの操作は防ぎます)。
  • WebP の素材、BT.709 以外の色の動画は使えません。

まだ人の目で確かめていないこと

  • sample の台本で number → build → prompts → 素材 → bubbles → render を通し、画面の配置と output.mp4 が一致することの、最終の目視確認(受け入れ条件)。
  • 30 分級の性能試験(cargo test -p s2v-cli --release --test render_perf -- --ignored --nocapture)。
  • bubbles のドラッグの途中のキャンセル(ウィンドウの外へ出るなど)。
