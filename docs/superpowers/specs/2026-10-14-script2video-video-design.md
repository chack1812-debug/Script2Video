# Script2Video 映像工程(②③④)設計書

日付: 2026-10-14 / 状態: 承認済み(2026-10-14、節ごとに Human が承認) / 前提: [設計書(①)](2026-10-12-script2video-design.md)、[台本仕様.md](../../../台本仕様.md)

本書は、①の設計書 §7〜§9(契約のみ)を置き換える。②プロンプト生成、③吹き出し・ト書きの配置、④最終合成を定める。①の `timeline.json` は本書の §3 で v3 に拡張する。

## 1. 目的と決定事項

肉声から作った `full_dialogue.wav` と台本から、完成動画 `output.mp4` を作る。Script2Voice の肉声版に当たる。

Human の決定(2026-10-14):

| 項目 | 決定 |
|---|---|
| 画面の構成 | 挿絵または動画クリップを全面に出し、その上に**吹き出し**(台詞)と**ト書き**(四角い枠)を重ねる。**字幕は付けない**。立ち絵は使わない |
| 文字の向き | 吹き出しの台詞もト書きも**縦書き** |
| ト書きの入力 | 台本に `#note` で書き、位置・大きさは③の GUI で調整する |
| ト書きの表示時間 | 書いた位置から、次の区切り(次の `#note`・`#cut`・シーンの終わり)まで |
| ②の範囲 | **プロンプトの生成まで**。画像・動画の生成は人(または AI が外部ツール)で行い、決められた名前で置く。本体は生成 API を呼ばない |
| 素材の単位 | シーンごと。`#cut` でシーン内の素材を切り替えられる |
| 動画素材が短いとき | 最後のコマで止める(既定)。`loop` 指定でループ。長いときは切り詰める |
| 吹き出しの大きさの調整 | 文字の大きさは一定(設定値)。吹き出しの大きさを変えると折り返しが変わる。文字が入りきらない大きさにはできない |
| 描画方式 | Rust で吹き出し・ト書きを PNG に描き(縦書きの組版を含む)、④はそれを ffmpeg で重ね、③の GUI は同じ PNG を表示する。描画のコードを1つにして、プレビューと完成動画の見た目を一致させる |
| 実装の順 | 計画 2a(④)→ 2b(②)→ 2c(③) |

## 2. コマンドと構成

| コマンド | 段階 | 入力 | 出力 |
|---|---|---|---|
| `number` | 既存(拡張) | 台本 | 番号付きの台本。`#cut`・`#note` にも番号を付ける |
| `build` | ①(拡張) | 台本、`voices/` | 既存の出力。`timeline.json` を v3 にする |
| `prompts` | ② 新規 | `timeline/timeline.json` | `prompts/S01.md` …、`prompts/index.md` |
| `bubbles` | ③ 新規 | `timeline/timeline.json`、`tracks/` の素材、`full_dialogue.wav`、`bubbles.json` | `bubbles.json`(+ `bubbles.json.bak`) |
| `render` | ④ 新規 | `full_dialogue.wav`、`timeline/timeline.json`、`tracks/` の素材、`bubbles.json`(任意) | `output.mp4` |

すべて `script2video <コマンド> <台本ファイル>` の形で、台本フォルダを基準にする。

### 2.1 クレート

| クレート | 役割 |
|---|---|
| `s2v-core`(既存) | `#cut`・`#note` の解析と採番、カットとト書きの時刻 |
| `s2v-export`(既存) | `timeline.json` v3 |
| `s2v-render`(新規) | 縦書きの組版、吹き出し・ト書きの PNG の描画、自動配置、`bubbles.json` の型と検証、素材の照合。③と④が共用する |
| `s2v-video`(新規) | ffmpeg による合成(④)。Script2Voice の `s2v-video` の考え方(素材の割り当て、ffmpeg 呼び出し)を参考に、新しく書く |
| `s2v-bubbles`(新規) | ③のローカルサーバーと埋め込みの HTML/JS |
| `s2v-cli`(既存) | コマンド `prompts`・`bubbles`・`render` の追加 |

### 2.2 台本フォルダの構成(追加分)

```
台本フォルダ/
  台本.txt
  full_dialogue.wav
  output.mp4          ← render が出力
  bubbles.json        ← bubbles が出力(.bak も)
  Process.log
  prompts/            ← prompts が出力(毎回作り直す)
    index.md
    S01.md
  timeline/timeline.json
  tracks/
    dialogue.wav bgm.wav se.wav   ← build が出力
    S01.png  S01_C02.mp4 …        ← 人が置く素材
  work/render/        ← render の中間ファイル
```

- `build` が `tracks/` で書き換え・削除するのは、自分の出力する wav(`dialogue.wav`・`bgm.wav`・`se.wav`)だけで、素材には触れない。`output.mp4`・`bubbles.json`・`prompts/` にも触れない。
- `Process.log` は `build` が作り直す。`prompts` と `render` は、自分の区切り(`== render 2026-10-14 12:34:56 ==` など)を付けて**追記**する。

## 3. 台本の追加命令と `timeline.json` v3

### 3.1 `#cut`

```
#paragraph[S02] 港の朝
#visual 朝焼けの港。漁船が並ぶ。
#note[N01] 翌朝、港。
[S02-L001] A:おはよう
#cut[C02]
#visual (video loop) 波が岸壁に打ち寄せる。
[S02-L002] B:早いね
#note[N02] 二人は黙って海を見る。
#pause 2000
```

- `#cut` はシーンの中で素材を切り替える。シーンの頭は暗黙のカット `C01` で、台本には書かない。
- `[C02]` は `number` が書き込む。カット番号は**シーンごとに** `C02` から振る。人は省略してよい。完全な ID は `S02-C02`。
- `#cut` の後ろに名称などは書かない(書かれていればエラー)。
- `#visual` は、直前の `#cut`(無ければシーンの頭のカット `C01`)に属する。同じカットの複数の `#visual` は連結する(既存の規則)。
- `#visual` の印: 行頭の括弧の中に、空白区切りで `image`・`video`・`loop` を書ける(`(video loop)`)。`image` と `video` は排他(両方あればエラー)。`loop` は動画の素材をループさせる指定で、印の種類が無い・`image` でも書ける(素材が画像なら無視する)。未知の語はエラー。

### 3.2 `#note`

- `#note 本文` はト書き。本文は空にできない(エラー)。
- `[N01]` は `number` が書き込む。ト書き番号は**シーンごとに** `N01` から振る。完全な ID は `S02-N01`。
- 本文は1行で書く。縦書きの折り返しは自動で行う。区切りたいところには全角空白を入れる。

### 3.3 採番(`number`)の拡張

- `#cut` と `#note` に番号を書き込む。規則は台詞と同じ: 既存の番号は変えない、欠番を詰めない、シーンの中で再利用しない、重複はエラー。
- `.ids` に `max_cut.S01=<n>` と `max_note.S01=<n>` を追加する(1シーン1行)。カットの番号は2から始まるので、`max_cut` の初期値は1とする。
- `S00`(最初の `#paragraph` より前)にも `#cut`・`#note` を書ける。

### 3.4 時刻

用語: **現在位置**は、`#se` をオプション無しで書いたときの位置(台本仕様 §2.7、①の設計書 §5.5 の `cursor`)とする。

- **シーンの映像区間**: シーンの並びで i 番目のシーンの映像区間を `[vs_i, vs_{i+1})` とする。`vs_1 = 0`、`vs_i = scenes[i].start_ms`(i ≧ 2)、最後のシーンの終わりは `duration_ms`。長さ 0 のシーン(同じ時刻に始まるシーンが続いた場合)は映像に現れず、警告する。
- **カット**: `C01` はシーンの映像区間の始めから始まる。`#cut` のカットは、その行の現在位置から始まる。ただし、シーンの映像区間の内側に収める(区間の始めより前なら始めに、終わりより後なら終わりにする)。各カットは次のカットの始め、またはシーンの映像区間の終わりまで続く。長さ 0 のカット(たとえば `#cut` がシーンの最初の台詞より前にあって `C01` が長さ 0 になる場合)は映像に現れない。`C01` が長さ 0 のときは警告しない(よくある書き方のため)。それ以外の長さ 0 のカットは警告する。
- **ト書き**: その行の現在位置から始まり、シーンの映像区間の内側に収める(カットと同じ)。終わりは、同じシーンの次の `#note` の始め、次のカットの始め、シーンの映像区間の終わりのうち最も早いもの。長さ 0 になるト書きは警告し、表示しない。
- **吹き出し**: 台詞の `start_ms` から `end_ms` まで表示する。`bubbles.json` の `start_offset_ms`・`end_offset_ms` で前後を調整できる(§5.2)。重なった台詞は吹き出しも同時に出る。不足(`missing: true`)の台詞も、仮の無音の位置に吹き出しを出す。
- 吹き出しとト書きは、カットやシーンの区切りをまたいで表示してよい(絶対時刻で重ねる)。

### 3.5 `timeline.json` v3

v2 からの変更点だけを示す。`schema_version` は 3。後続工程(`prompts`・`bubbles`・`render`)は 3 以外を拒否する。

```jsonc
{
  "schema_version": 3,
  "script_sha256": "…",          // build 時点の台本ファイルの SHA-256(16進小文字)
  "audio_sha256": "…",           // build が書いた full_dialogue.wav の SHA-256
  "scenes": [
    {
      "id": "S02", "name": "港の朝", "index": 2, "silent": false,
      "start_ms": 20500, "end_ms": 41000,
      "video_start_ms": 20500, "video_end_ms": 43000,   // §3.4 のシーンの映像区間
      "cuts": [
        { "id": "S02-C01", "start_ms": 20500, "end_ms": 30000,
          "visual": { "text": "朝焼けの港。漁船が並ぶ。", "kind": "image", "loop": false } },
        { "id": "S02-C02", "start_ms": 30000, "end_ms": 43000,
          "visual": { "text": "波が岸壁に打ち寄せる。", "kind": "video", "loop": true } }
      ],
      "notes": [
        { "id": "S02-N01", "text": "翌朝、港。", "start_ms": 20500, "end_ms": 30000 }
      ]
    }
  ]
}
```

- v2 の `scenes[].visual` は廃止し、`cuts[].visual` に移す。`#visual` が無いカットは `visual` が null。`kind` は `image` | `video` | null。
- `cuts[]` には長さ 0 のカットも含める(`start_ms == end_ms`)。`notes[]` も同じ。後続工程は長さ 0 のものを表示しない。
- それ以外のフィールド(`lines`・`takes`・`events`・`cast` など)は v2 のまま。

## 4. ④最終合成(`render`)

### 4.1 処理の流れ

1. **読み込みと検査**
   - `timeline/timeline.json` を読む。無い・`schema_version` が 3 でない → エラー 2(`build` のやり直しを促す)。
   - `full_dialogue.wav` の SHA-256 が `audio_sha256` と違う → エラー 2(`timeline.json` と音声が別の `build` のもの)。
   - 台本ファイルの SHA-256 が `script_sha256` と違う → 警告(`build` 後に台本が変わった)。
   - `bubbles.json` があれば読んで検証する(§5.2)。壊れている → エラー 2。無ければ全項目を自動配置にする。
   - ffmpeg・ffprobe を探す(設定のパス、無ければ PATH)。無い → エラー 2。フォントが読めない → エラー 2。
2. **素材の照合**(§4.3)。不足があれば一覧を出してエラー 2。`default_image` が設定されていれば代わりに使い、警告にとどめる。
3. **吹き出し・ト書きの描画**: 表示する全項目(長さ 0 でないもの)の配置を決め(`bubbles.json` の値、無ければ自動配置 §4.4)、`s2v-render` で透明な PNG を `work/render/overlays/S01-L003.png` などに描く。
4. **カットごとの区間ファイル**: 長さ 0 でないカットごとに ffmpeg を1回呼び、映像だけの区間ファイル `work/render/seg/S01-C01.mp4` を作る(§4.5)。
5. **連結と音声**: 区間ファイルを ffmpeg の concat で連結し(再エンコードなし)、`full_dialogue.wav` を AAC にして多重化し、`work/render/output.tmp.mp4` に書く。成功したら `output.mp4` に置き換える(同じボリューム内の rename)。失敗時は `output.mp4` を変更しない。
6. **出力の検証**: ffprobe で、映像と音声のストリームがあること、解像度と fps が設定どおりであること、映像の長さと `duration_ms` の差が1コマ以内であることを確かめる。外れたら エラー 2(`output.mp4` は置き換えた後なので、Process.log と標準エラーに明記する)。

`work/render/` は毎回作り直す(古い区間ファイルを使い回さない)。

### 4.2 時刻とコマ

- `frame(t) = round(t × fps / 1000)`(t はミリ秒。0.5 は切り上げ)。動画全体のコマ数は `ceil(duration_ms × fps / 1000)`。
- カットの区間ファイルのコマ数は `frame(end) − frame(start)`(最後のカットだけは全体のコマ数 − `frame(start)`)。コマ数が 0 になるカットは作らない。各区間は境目の絶対時刻を1回だけ丸めるので、カットが多くても誤差は積み重ならない。
- 吹き出し・ト書きは、コマ f が `frame(表示開始) ≦ f < frame(表示終了)` のとき表示する。区間ファイルの中では、区間の先頭からの相対コマで指定する。

### 4.3 素材の照合

- 探す場所は `tracks/`。名前は、`C01` は `S01`、それ以外は `S01_C02`(カット ID の `-` を `_` にした形)。拡張子は、画像が `png`・`jpg`・`jpeg`・`webp`、動画が `mp4`・`mov`・`webm`(大文字小文字を区別しない)。
- 同じカットに2つ以上の素材がある(`S01.png` と `S01.mp4` など) → エラー 2(どちらを使うか決めない。人が取り除く)。
- **同名シーンの共用**: シーンの `C01` に素材が無く、台本の前方に同じ名称(空でない)のシーンがあれば、その最も近いシーンの `C01` の素材を使う(Script2Voice の「離れた同名シーンの素材共有」)。`C02` 以降は共用しない。
- `#visual` の `kind` と素材の種類が違う(`video` 指定に png)→ 警告して素材を使う。
- 素材の中身(読めるか、寸法)は ffprobe で確かめる。読めない → エラー 2。

### 4.4 自動配置

`bubbles.json` に無い項目の位置と大きさを決める。決定的(同じ入力なら同じ結果)。

- **大きさ**: §6.2 の `min_size`。1列の高さの上限は画面の高さ × `bubble_max_height_ratio`(既定 0.55。ト書きは `note_max_height_ratio`、既定 0.6)。
- **ト書き**: 画面の右上(余白 `margin` 既定 40px)に置く。ト書き同士は時間が重ならない(§3.4)ので、すべて同じ位置になる。
- **吹き出し**: 開始時刻の順(同時なら台本の並び)に1つずつ置く。上端は余白の位置。右端から左へ向けて、時間が重なる配置済みの項目(ト書き・吹き出し・`bubbles.json` で手動配置した項目)と重ならない最も右の x を、`bubble_gap`(既定 24px)の間隔で探す。どこにも置けなければ右端に置いて警告する。
- **尻尾**: 下向き。吹き出しの下端中央から、下へ `tail_length`(既定 80px)の点を先端とする。

### 4.5 区間ファイルの作り方

- 画像: `-loop 1` で読み、`fit` に従って拡大・縮小する。`contain`(既定)は全体を収め、余りを `background`(既定 黒)で埋める。`cover` は画面を埋め、はみ出しを中央で切る。
- 動画: 音声は捨てる。fps を設定値に変換し、`fit` を同様に適用する。`loop: true` は `-stream_loop -1` でループさせる。それ以外は、短ければ `tpad=stop_mode=clone` で最後のコマを延ばし、長ければ切り詰める。
- 吹き出し・ト書き: 区間の時間に表示が重なる PNG を入力に加え、`overlay` に表示するコマの範囲を指定する。重ねる順は、ト書き → 吹き出し(開始時刻の順)。
- 出力の形式: H.264(`libx264`、`crf` 既定 20、`preset` 既定 medium、`yuv420p`)。全区間を同じ設定で作り、concat で再エンコードせずに連結できるようにする。
- ffmpeg の引数は、文字列の配列として組み立てる(シェルを経由しない)。組み立ては関数に分け、テストで検証する。

### 4.6 設定(`config.toml` の `[render]`)

| キー | 既定 | 意味 |
|---|---|---|
| `width` / `height` | 1920 / 1080 | 解像度 |
| `fps` | 30 | フレームレート(整数) |
| `crf` / `preset` | 20 / "medium" | H.264 |
| `audio_bitrate` | "192k" | AAC |
| `fit` | "contain" | `contain` / `cover` |

## 5. ③吹き出し・ト書きの配置(`bubbles`)

### 5.1 起動と終了

- `script2video bubbles 台本.txt [--port N] [--no-open]`。127.0.0.1 の空いているポート(`--port` で指定可)でサーバーを起動し、既定のブラウザで `http://127.0.0.1:<port>/?token=<トークン>` を開く(`--no-open` なら URL を表示するだけ)。
- 起動時の検査は `render` の手順 1 と同じ(`timeline.json`、`audio_sha256`、フォント)。素材の不足は起動を妨げない(画面に「素材なし」と表示する)。
- 画面の「終了」ボタンか Ctrl+C で終わる。保存していない変更があれば、画面で確認してから終わる。

### 5.2 `bubbles.json`

```json
{
  "version": 1,
  "canvas": { "w": 1920, "h": 1080 },
  "items": {
    "S01-L003": { "kind": "bubble", "x": 1200, "y": 80, "w": 220, "h": 420,
                  "tail": { "dx": 0, "dy": 290 }, "start_offset_ms": 0, "end_offset_ms": 0 },
    "S01-N01":  { "kind": "note", "x": 1700, "y": 40, "w": 160, "h": 380,
                  "start_offset_ms": 0, "end_offset_ms": 0 }
  }
}
```

- 鍵は台詞 ID・ト書き ID。`kind` は ID の種類と一致しなければならない(`L` は bubble、`N` は note)。
- `x`・`y` は左上の座標、`w`・`h` は大きさ(いずれも `canvas` 上の整数ピクセル)。`tail` は吹き出しの中心からの尻尾の先端の相対位置。null なら尻尾なし。ト書きは `tail` を持たない。
- **手動配置の項目だけを保存する**。GUI で触っていない項目は保存せず、毎回自動配置する(§4.4。手動配置の項目は障害物として扱う)。GUI の「自動配置に戻す」は項目を削除する。
- 解像度が `canvas` と違うときは、x・w を幅の比、y・h を高さの比で拡大・縮小し(丸めは四捨五入)、尻尾も同様にする。
- 表示時刻は、元の時刻に offset を足し、`[0, duration_ms]` に収める。結果の開始が終了以上になる項目 → エラー 2(読み込み時)。GUI は保存時に同じ検査をして拒否する。
- 台詞やト書きの本文が変わり、保存されている大きさが新しい `min_size` より小さい → 足りない方向だけ最小まで広げて警告する(右下へ広げる。画面外に出るなら内側へ寄せる)。
- `timeline.json` に存在しない ID → 警告して無視する。ファイルからは消さない(採番の都合で一時的に消えることがあるため)。
- 検証: 未知のキー、負の大きさ、`version` 違い、JSON の破損 → エラー 2。
- 保存は、既存のファイルを `bubbles.json.bak` にコピーしてから、一時ファイルに書いて置き換える。

### 5.3 画面

- **左**: シーン → カット → 台詞・ト書きの一覧。選ぶと、その項目の表示開始の時刻へ移動し、項目を選択する。手動配置の項目には印を付ける。
- **中央**: 16:9 の画面(ウィンドウに合わせて縮小表示。座標は `canvas` のピクセルで扱う)。現在の時刻のカットの素材(画像、または動画のその時刻のコマ)を背景に、その時刻に表示中の吹き出しとト書きを、サーバーが描いた PNG で重ねる。
- **下**: 時刻のスライダー、再生/停止。再生中は `full_dialogue.wav` を鳴らし、吹き出しの出入りと動画の素材を同じ時刻に合わせる。
- **右**: 選択中の項目の数値(x、y、w、h、尻尾、表示開始・終了の offset)。数値を直接入力できる。
- **操作**: 本体のドラッグで移動、四隅のドラッグで大きさ(最小より小さくはならない)、尻尾の先端のドラッグ、矢印キーで 1px(Shift で 10px)、「自動配置に戻す」、元に戻す/やり直し(Ctrl+Z / Ctrl+Y、その起動中だけ)、保存(Ctrl+S)。
- **表示の更新**: ドラッグ中はブラウザが枠の輪郭だけを描く。手を離すとサーバーに PNG を要求し、差し替える。

### 5.4 サーバーと API

`tiny_http` による同期のサーバー。1つの接続ずつ処理する。HTML/JS/CSS は実行ファイルに埋め込む(外部のライブラリ・CDN を使わない)。

| メソッドとパス | 内容 |
|---|---|
| `GET /` | 画面 |
| `GET /api/state` | timeline の必要部分、カットごとの素材の URL、現在の `bubbles.json`、各項目の自動配置の結果と `min_size` |
| `POST /api/render` | 1項目の配置(kind、ID、w、h、尻尾)を受け、PNG を返す。`min_size` より小さければ 422 |
| `POST /api/layout` | 手動配置の項目一式を受け、残りの自動配置の結果を返す(保存はしない) |
| `POST /api/save` | 手動配置の項目一式を検証して `bubbles.json` に保存する。不正なら 422 で理由を返す |
| `GET /media/tracks/<名前>` | 素材。照合で見つかったファイル名だけを許す |
| `GET /media/audio` | `full_dialogue.wav`(Range 要求に対応) |
| `POST /api/quit` | 終了 |

**安全**:

- 127.0.0.1 だけで待ち受ける。
- 起動ごとに 32 バイトの乱数のトークンを作る。`/` はクエリの `token` で確かめ、画面は以降の要求でヘッダー `X-S2V-Token` を付ける(メディアはクエリの `token`)。合わなければ 403。
- `Host` ヘッダーが `127.0.0.1:<port>` か `localhost:<port>` でなければ 403(DNS リバインディング対策)。
- `POST` は `Content-Type: application/json` だけを受け、本文は 1 MiB まで。
- メディアは、照合の結果の一覧(素材のファイル名)と `full_dialogue.wav` だけを返す。要求のパスをファイルシステムのパスとして解釈しない。

## 6. 描画部品(`s2v-render`)

### 6.1 縦書きの組版

- フォントを `ttf-parser` で読み、`rustybuzz` で**縦書き方向**(`Direction::TopToBottom`、`vert`・`vrt2` 機能)に整形する。句読点・括弧・長音などの縦書き用の字形と位置は、フォントの情報に従う。フォントに縦書きの寸法(`vhea`/`vmtx`)が無ければエラー 2。
- 列は右から左へ並べる。1列の文字数は、枠の内側の高さに収まる数。
- **禁則**: 列の頭に置かない文字(`、。，．・：；？！ー」』）】〉》ぁぃぅぇぉっゃゅょゎァィゥェォッャュョヮヵヶ々〜` と対応する全角記号)は、前の列の末尾へ追い込む(1文字まで。追い込めなければそのまま)。列の末尾に置かない文字(`「『（【〈《`)は次の列へ送る。
- **半角の英数字**: 連続する半角数字が2文字以下なら縦中横(横に並べて1文字分に収める)。それ以外の半角英数字・記号の連続は、90° 回転して並べる。
- 台詞の本文に含まれる改行は無い(台本は1行1台詞)。全角空白はそのまま1文字分の空きとして扱う。

### 6.2 関数

- `layout(text, inner_h) -> Layout`: 列の配置(各字形の位置・回転)。
- `min_size(kind, text) -> (w, h)`: その項目が取れる最小の大きさ。1列の高さの上限(§4.4 の比)のもとで列数が最小になる組版の、外形の大きさ。手動で大きさを決めたときも、`w`・`h` がこれ以上であることを要求する。
- `render(spec) -> RgbaImage`: 項目1つの透明な PNG。大きさは尻尾を含む外接矩形で、`spec` は種類、本文、`w`・`h`、尻尾、設定を含む。返す画像の左上の画面上の位置も返す。
- 描画は `tiny-skia`。字形の輪郭を `ttf-parser` から取り出してパスにする。
- **決定的**: 同じ入力(フォントのファイルを含む)から同じ画素を出す。テストで固定する。

### 6.3 形

- 吹き出し: 枠いっぱいの楕円に近い角丸の形(縦書きに合う縦長)。尻尾は、本体の縁の2点と先端を結ぶ三角形で、本体と一体の輪郭として縁取りする。
- ト書き: 長方形の枠。

## 7. ②プロンプト生成(`prompts`)

- `prompts/` を作り直し(中のファイルを消してから書く。`prompts/` 以外には触れない)、シーンごとに `prompts/S01.md` を書く。カットごとに節を分け、各節に次を書く。
  - 作る素材のファイル名(`tracks/S01.png` など。`kind` が null なら「png か mp4」)。長さ 0 のカットは節を作らない。
  - 種類と、動画ならカットの長さ(秒、小数1桁)と `loop` の有無。
  - プロンプト本文: (1) `[prompts]` の `style`、(2) シーン名、(3) カットの `#visual`、(4) 登場人物とその外見(`cast[].appearance`。外見が無い役は名前だけ)、(5) `[prompts]` の `suffix`(既定「縦横比 16:9。画像の中に文字・吹き出しを入れない。」)。
  - 登場人物は、カットの時間 `[start, end)` に `start_ms` がある台詞の話者(台本の並びで初出順、重複なし)。
  - 同名シーンの共用(§4.3)で素材が要らない `C01` は、「S01 の素材を共用する」と書いてプロンプトを省く。
- `prompts/index.md`: 全カットの表(カット ID、ファイル名、種類、長さ、素材の有無、共用元)。
- 終了コード: 0 成功、1 警告(`#visual` の無いカットがある)、2 失敗(`timeline.json` が無い・版違い、書き込み失敗)。
- 設定 `[prompts]`: `style`(既定 空)、`suffix`(既定は上記)。

## 8. テスト

- **台本と timeline**: `#cut`・`#note`・`#visual` の印の解析と誤り(`#cut` の名称、空の `#note`、`image`+`video`、未知の印)。採番(シーンごとの振り直し、既存番号の保持、欠番、重複、`.ids` の `max_cut`/`max_note`)。カット・ト書きの時刻(§3.4 の各規則、映像区間への収め込み、長さ 0、無言のシーン、`#pause` との組み合わせ、`S00`)。v3 の書き出しのゴールデン、`script_sha256`・`audio_sha256`。
- **s2v-render**: 組版の結果を数値で固定する(列数、字形の位置、禁則の追い込みと送り、縦中横、回転)。最小の大きさ。小さな PNG の画素比較(決定性)。自動配置(重ならないこと、手動配置を避けること、置けないときの警告)。`bubbles.json` の検証・拡大縮小・最小への拡大。素材の照合(優先と重複、同名シーンの共用、拡張子の大小)。フォントのテストは、リポジトリに置く小さな OFL のフォントの部分集合を使う(システムのフォントに依存しない)。
- **render**: コマの丸め(多数のカットで合計が全体のコマ数に一致)、ffmpeg の引数の組み立て(画像・動画・loop・contain/cover・重ね)。ffmpeg を使う結合テスト(短い台本、単色の画像、数秒の動画、吹き出し付き)で mp4 を作り、ffprobe で長さ・解像度・ストリームを確かめ、指定の時刻のコマを取り出して吹き出しの画素があることを確かめる。ffmpeg が無い環境では飛ばす。置き換えの失敗時に `output.mp4` が変わらないこと。
- **prompts**: 出力の Markdown のゴールデン(登場人物の判定、`#visual` の無いカット、共用、長さ 0 のカット)。
- **bubbles のサーバー**: トークン・Host・Content-Type・本文の大きさの検査、メディアの許可一覧(`..`・絶対パス・一覧に無い名前の拒否)、保存と `.bak`、最小より小さい・offset の逆転の拒否。画面の操作は Chrome の自動操作で確認する。
- 検証コマンド: `cargo fmt --check` / `cargo clippy --workspace --all-targets -- -D warnings` / `cargo test --workspace`。

## 9. 受け入れ条件

- sample の台本で `number` → `build` → `prompts` → 素材を置く → `bubbles` で調整 → `render` と進め、`output.mp4` ができる。
- 動画で、縦書きの吹き出しが台詞に合わせて出入りし、ト書きの枠が次の区切りまで出ていて、動画の素材が最後のコマで止まる(`loop` ではループする)ことを、Human が目で確認する。
- GUI で見た配置と、`render` の結果の同じ時刻のコマが一致する。
- 上記の検証コマンドがすべて通る。
