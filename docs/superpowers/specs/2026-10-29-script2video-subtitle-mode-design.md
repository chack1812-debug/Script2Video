# Script2Video 字幕モード 設計書

日付: 2026-10-29 / 対象: `render` と `bubbles`、`config.toml` の `[render]`

## 1. 目的(なぜ)

吹き出しが画面の邪魔になる動画がある。台詞を吹き出しではなく字幕で出して、動画を仕上げられるようにする。
吹き出しと字幕は両立させず、**どちらか一方**で動画を仕上げる。

## 2. 目標・非目標・アンチゴール

### 目標
- `config.toml` の `[render] style` で、吹き出しモードと字幕モードを切り替える。
- 字幕モードでは、台詞を画面の最下段に横書きの字幕として出す(最大 3 行)。字幕の左上に発言者の名前を出す。
- 字幕の文字色・囲い・帯・発言者名の囲いなどを `config.toml` で設定できる。
- ト書きは字幕モードでも画面に出す。表示は現状どおり(縦書き・同じ枠・同じ自動配置)。
- 字幕が 4 行以上になる台詞があるときは、`output.mp4` を作らずに終了する(終了コード 1)。台詞を分割して台本を作り直すため。

### 非目標(今回やらない)
- `bubbles` の画面で文字の大きさを設定すること(後で実装する。別の bead で起票する)。
- 字幕の位置の手動調整(最下段に固定)。
- 4 行以上の字幕の自動分割(台本の側で分割する)。
- 吹き出しと字幕の混在。
- `--subtitle` のようなコマンドラインのオプション(切り替えは `config.toml` だけ)。

### アンチゴール
- `style = "bubble"`(既定)の既存の動画の見た目や出力が、1 画素でも変わること。
- 4 行以上の台詞があるのに、黙って切り詰めて `output.mp4` を作ること。
- 字幕モードの失敗で、既存の `output.mp4` を壊すこと(失敗時は変えない。現状の `render` と同じ)。

## 3. 現状(コードの事実)

- `build` は `timeline/subtitles.srt` を出すが、`render` は字幕を動画に焼き込んでいない。`render` が重ねるのは吹き出し(`ItemKind::Bubble`)とト書き(`ItemKind::Note`)だけ(`crates/s2v-render/src/scene.rs`)。
- 項目は `build_items`(台詞とト書きを `Item` にする)→ `place_items`(手動配置と自動配置)→ `draw_item`(描画)→ `compose`(重ね画像)の順で作る。`render` と `bubbles` が同じ関数を使う。
- 台詞(`LineEntry`)は発言者を `cast` で持つ。`Timeline.cast` は `CastEntry { name, speaker, appearance }`。
- 文字の大きさ `font_size`(既定 44px)は `[render]` にあり、吹き出しとト書きが共通で使っている。**字幕も同じ値を使う。新しい項目は足さない。**

## 4. 決めたこと(ユーザーの決定)

| 項目 | 決定 |
|------|------|
| 切り替え方法 | `config.toml` の `[render]` に `style = "bubble" \| "subtitle"` を書く(既定 `"bubble"`)。コマンドラインのオプションは作らない |
| 字幕の位置 | 最下段 |
| 字幕の行数 | 最大 3 行 |
| 発言者名 | 字幕の左上に表示する |
| ト書き | 字幕モードでも画面に出す。表示は現状どおり |
| 字幕の見た目 | 文字色・囲い・帯・発言者名付きの囲いなどを `config.toml` で設定できる |
| 4 行以上の台詞 | 「台詞が四行以上」の警告を出して終了する。終了コード 1。台詞を分割して台本を作り直す |
| 文字の大きさ | `font_size` を吹き出し・字幕で共通に使う。`bubbles` 画面での設定は後で実装する |

## 5. 振る舞い

### 5.1 `style = "subtitle"` の `render`
1. 起動時の検査(`prepare`)は現状どおり。
2. 台詞を字幕として組み、各台詞の行数を数える。
3. 4 行以上の台詞が 1 つでもあれば、**全部の該当台詞**を `Process.log` と画面に報告して終了する(終了コード 1)。報告は台詞 ID・発言者・本文を含み、「台詞が四行以上」の文言を入れる。`output.mp4` は作らず、既存の `output.mp4` も変えない。
4. 問題なければ、字幕とト書きを重ね画像にして、現状どおり合成する。

### 5.2 字幕の見た目
- 横書き。画面の左右の余白は既存の `margin` を使う。最下段には下の余白を空けて置く。
- 台詞ごとに、帯(塗り・枠線・余白)の中に本文を折り返して入れる。帯の高さは、その台詞の行数(1〜3)に合わせる。下端は最下段にそろえる。
- 発言者名は、帯の左上に付く囲い(ラベル)に入れる。
- 文字色、文字の縁取り、帯、発言者名の囲いは、`config.toml` で設定できる。

### 5.3 設定項目(`[render]`)
名前と既定値は下記を提案する(§8 の「ビルダーに任せる」の範囲で変えてよい)。

| キー | 既定 | 意味 |
|------|------|------|
| `style` | `"bubble"` | `"bubble"` または `"subtitle"` |
| `subtitle_text_color` | `"#FFFFFF"` | 字幕の文字色 |
| `subtitle_outline_color` | `"#000000"` | 文字の縁取りの色 |
| `subtitle_outline_width` | `3.0` | 文字の縁取りの太さ(0 で縁取りなし) |
| `subtitle_band_fill` | `"#000000"` | 帯の塗り |
| `subtitle_band_opacity` | `0.0` | 帯の塗りの不透明度(0〜1) |
| `subtitle_band_stroke` | `"#FFFFFF"` | 帯の枠線の色 |
| `subtitle_band_stroke_width` | `0.0` | 帯の枠線の太さ(0 で枠なし) |
| `subtitle_padding` | `20` | 帯の内側の余白 |
| `subtitle_margin_bottom` | `40` | 画面の下端から帯までの余白 |
| `speaker_text_color` | `"#FFFFFF"` | 発言者名の文字色 |
| `speaker_fill` | `"#333333"` | 発言者名の囲いの塗り |
| `speaker_stroke` | `"#FFFFFF"` | 発言者名の囲いの枠線の色 |
| `speaker_stroke_width` | `2.0` | 発言者名の囲いの枠線の太さ |
| `speaker_padding` | `10` | 発言者名の囲いの内側の余白 |

- 色は既存と同じ `#RRGGBB`。不正な値、範囲外の値は、既存の項目と同じ検査でエラー(終了コード 2)にする。
- 最大行数 3 は設定項目にしない(定数)。

### 5.4 `bubbles` コマンド
- `style = "subtitle"` のときも起動できる。画面にはト書きだけを出し、台詞(字幕)は出さない。ト書きの配置の調整と保存は現状どおり。
- 台詞の表示時刻の補正(`start_offset_ms`・`end_offset_ms`)は、字幕でも効く(`build_items` が共通のため)。
- 画面で文字の大きさを設定する機能は、今回は作らない(後で実装する)。

### 5.5 ビルダーチェックで詰めた点(**設計者の判断**。ユーザーの決定ではない)

- **発言者名**: `LineEntry.cast`(台本の役名)を出す。台本仕様 §2.4 のとおり、`CastEntry.speaker` は合成エンジンに渡す話者名で、表示用ではない。役名が空の台詞は、ラベルを出さない(空のラベルを描かない)。
- **「3 行」の範囲**: 本文だけの行数。発言者名のラベルは行数に入れない。ラベルは帯の上辺の左上に接して置き、帯の本文領域を狭めない(帯の外にはみ出す分は、帯の高さの外側として積み上げの計算に含める)。
- **行数の報告**: 4 行以上の台詞の報告に、折り返し後の行数を書く(例: `S01-L012 田中: 5 行`)。台本をどこで分けるかの目安にするため。
- **積み上げが画面に収まらない場合**(同時に出る台詞が多い場合): 4 行以上の台詞と同じく、`output.mp4` を作らずに終了する(終了コード 1)。台詞 ID を報告する。見えない字幕を黙って出さないため(アンチゴール)。
- **`bubbles.json`**: 字幕モードの `bubbles` は、保存のときに台詞の手動配置を消さず、そのまま保持する(吹き出しモードへ戻したときに失われないようにする)。字幕モードでは台詞の手動配置は使わない。
- **ト書きと字幕の重なり**: 重なると判定したら警告する(終了コード 1 で、出力は作る)。ト書きは縮めない。
- **吹き出しモードの同一性**: 既存のテスト(golden・描画)がそのまま通ることで担保する。`style` が `"bubble"` のときは、既存の経路に字幕の処理を通さない。

## 6. 制約

- 既存の `style = "bubble"` の動作・出力・テストを変えない。
- `render` と `bubbles` が項目を同じ関数で作る構造を保つ(共通の関数に字幕を足す)。
- 横書きの組版は、既存の縦書きの組版(`layout`・`draw`)と同じフォントを使う。縦書きを壊さない。
- 作業は Beads で追う。コミットと push は、ユーザーが求めるまで行わない。

## 7. 受け入れ条件

- `style` を省略した `config.toml` で、既存のテストがすべて通り、出力が変わらない。
- `style = "subtitle"` で、台詞が最下段の字幕として出る。字幕の左上に発言者名が出る。ト書きは現状どおり出る。吹き出しは出ない。
- 字幕の文字色・縁取り・帯・発言者名の囲いが、`config.toml` の値に従って変わる。
- 4 行以上になる台詞があると、全部の該当台詞が報告され、終了コード 1 で終わり、`output.mp4` は作られない(既存の `output.mp4` も変わらない)。
- 3 行ちょうどの台詞は通る(境界の検査)。
- 同時に出る台詞の積み上げが画面に収まらないときは、終了コード 1 で止まり、`output.mp4` は作られない。
- 字幕モードの `bubbles` で保存しても、`bubbles.json` の台詞の手動配置が消えない。
- 取扱説明書・README・`config.toml` のコメントに、字幕モードと設定項目を書く。
- 映像の見た目の確認は Human が行う(字幕の位置・読みやすさ)。

## 8. ビルダーに任せること

- 設定項目の最終的な名前と既定値(§5.3 の提案から変えてよい)。
- 発言者名のラベルの形(帯の上辺の左上に接する、帯の左上の内側に重ねる、など)と、帯との重なり方。
- 同じ時刻に台詞が重なる(`overlap=` など)ときの字幕の並べ方。**ユーザーは決めていない。設計者の判断**: 後から始まる台詞を、先の台詞の上に積む。積んだ結果が画面に収まらないときは、§5.5 のとおり終了コード 1 で止める。
- 折り返しの規則(禁則処理を含む)と、行数を数える方法。
- 字幕の帯の幅(画面の幅から左右の余白を引いた幅を既定にする)。
- ト書きの枠と字幕の帯が重なるかどうかの判定の細部(§5.5 のとおり、重なれば警告する)。
- テストの構成(単体・golden・ffmpeg を使う統合)。

## 9. 後続の作業(別の bead)

- `bubbles` の画面で文字の大きさを選択・設定できるようにする。保存先(`config.toml` を画面から書き換えるか、`bubbles.json` に持たせるか)と、文字の大きさを変えたときに手動配置の枠へ文字が収まらなくなる問題を、そのときに決める。
